## Implementation considerations

- Map each displayed choice to its existing scale value ID; visual left-to-right order reverses the current scenario ordinal order so the criterion on each side matches the direction of preference.
- Preserve the configured five- or seven-point scale; these examples show seven points.
- Unanswered is a separate null state. Equal preference requires an explicit selection.
- Selection needs a visible checkmark, text feedback, keyboard support, and a visible focus indicator.
- Clear answer removes the selection; changing a choice does not imply it has been saved.
- The slider uses discrete stops. The choice tiles use a radio group with the same choices arranged vertically on narrow screens.
