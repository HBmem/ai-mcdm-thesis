# Public Safety Resource Allocation — Trial Test Data

These tables use linguistic preference values that can be imported into the stakeholder preference workflow and then compared against manual calculations and coded validation.

Preference interpretation: higher values mean the participant places more importance on that criterion. For Implementation Cost, a higher preference means stronger concern for keeping cost low. For Implementation Time, a higher preference means stronger concern for fast implementation.
